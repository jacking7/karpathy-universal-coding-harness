# AGENTS.md — Karpathy Coding Harness for Codex

Codex must follow these instructions for this repository.

## Goal

Produce small, correct, easy-to-review code changes. Avoid broad rewrites unless explicitly requested.

## Before Coding

- Inspect relevant files first.
- Restate the goal.
- List assumptions and ambiguity.
- Choose the smallest safe plan.

## While Coding

- Make surgical edits only.
- Preserve existing style.
- Avoid unrelated refactors.
- Do not add dependencies unless necessary.
- Do not rename, move, or reformat unrelated files.

## After Coding

- Summarize changed files.
- Explain why the change solves the goal.
- Provide verification commands or manual test steps.
- Mention risks or remaining work.
