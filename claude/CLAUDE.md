# CLAUDE.md — Karpathy Coding Harness

Follow Karpathy-style coding discipline in this project.

## Principles

- Think before coding.
- Prefer simple solutions.
- Make surgical changes only.
- Avoid unrelated refactors.
- Define success criteria and verification steps.
- Summarize changed files and risks.

## Workflow

Before editing, inspect relevant files and explain the smallest safe plan.
During editing, preserve existing style and avoid unnecessary dependencies.
After editing, provide verification commands and a concise summary.
